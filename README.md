# Aadhya International — Chocolate Panning Academy 🍫✨

A modern, responsive, 1:1 pixel-perfect website for **Aadhya International | Chocolate Panning Academy** built with React 19, Tailwind CSS v4, Lucide Icons, and Vite.

## 🚀 Features

- **Pixel-Perfect 1:1 Visual Fidelity**: Custom organic textures, warm chocolate tones, Playfair Display & Plus Jakarta Sans typography.
- **Edge-to-Edge Responsive Layout**: Zero side gutters with uniform full-bleed hero banners across all viewports.
- **Comprehensive Page Architecture**:
  - **Home**: Full-bleed hero banner, interactive offerings cards, signature courses single-row layout, chocolate process pipeline, and masterclass registration.
  - **About Us**: Center of excellence overview, founder Deepak Kumar bio, journey milestones.
  - **Training Programs**: 5-pillar feature strip, category filter pills, course cards.
  - **Consultancy**: Technical, production, and business consultancy services.
  - **Beginner & Professional Masterclasses**: Hands-on course curriculums, batch timings, brochure downloads.
  - **Enquiry & Contact**: Interactive enquiry modal, WhatsApp hotline, direct consultation booking.
- **Interactive Features**:
  - `EnquiryModal`, `BrochureModal`, and `WorkshopModal` popups with confetti animations.
  - Live filter tabs and animated carousel components.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: Canvas Confetti & Framer Motion

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/adminbiztechx/chocolate-panning-academy.git

# Navigate to the project directory
cd chocolate-panning-academy

# Install dependencies
npm install

# Run the local development server
npm run dev

# Build for production
npm run build
```
